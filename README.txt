# Aurora Hair & Beauty Equipment Website

Static website built from the supplied product images.

WhatsApp: 063 886 2322
Address: 3 South Street, Lorentzville, Johannesburg, 2094, South Africa

## Features
- Responsive professional storefront
- Product prices displayed in South African Rand (R)
- Category filters
- Every "Order on WhatsApp" button opens WhatsApp with the product name and price pre-filled
- Floating WhatsApp button
- No backend required

## Important
The prices included are suggested catalogue prices based on the supplied product range. Update them in the `products` array in `index.html` if you have your exact selling prices.
